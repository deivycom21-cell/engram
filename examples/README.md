# Example notes

`demo-notes/` contains **sample documents written for this repository** so you can try the
complete ENGRAM flow (import → relations → contextual recall → reconstruction → 3D graph)
without using your own data. They are not real records. `patrones-arquitectura.pdf` is
generated by `scripts/make_demo_pdf.py`.

```bash
engram ingest examples/demo-notes
engram reconstruct "¿Por qué abandoné mi anterior arquitectura?"
```

To remove them later, start with a fresh data directory (`ENGRAM_DATA_DIR=...`) or
archive the engrams from the Memory Inspector — ENGRAM never deletes on its own.
